# 0.3.1 release

This release supersedes the unpromoted 0.3.0 tag. It retains the [evidence-bank features and measurement limits](RELEASE-0.3.0.md), with a clean-host fix: prohibited vendor integration commands are rejected before searching for or invoking the vendor executable.

The six-job offline CI matrix covers Windows, Linux and macOS with Python 3.10 and 3.13, Node 20, behavioral tests and isolated installed-wheel verification.
