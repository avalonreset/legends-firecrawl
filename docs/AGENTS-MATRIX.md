# Multi-agent matrix

All harnesses discover this module through the one registered `cto-legends`
router skill (vendored at `skills/cto-legends/SKILL.md`). There is no
per-module skill directory and no per-host skill installer: run
`cto-legends install legends-firecrawl` to preview the install, then use the
`lfc` / `lax` launchers. Never install or fall back to Firecrawl MCP or the
vendor integration setup.
