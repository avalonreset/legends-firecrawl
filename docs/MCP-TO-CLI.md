# MCP intent to house route

This document is a migration map, not an installation guide.

| Old tool-shaped intent | Legends Firecrawl route |
|---|---|
| Scrape one URL | `lfc scrape <url>` |
| Discover site URLs | `lfc map <url>` |
| Search the web | `lfc search "<query>"` |
| Crawl a website | `crawl-preview`, then confirmed `crawl` |
| Check a crawl | `lfc crawl-status <id>` |
| Check credits | `lfc credits` |
| Use from Python | `legends_firecrawl.FirecrawlClient` or `packet_compat` |

There is no MCP fallback branch. Missing MCP tools are not a product failure.
