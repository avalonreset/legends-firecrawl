# Collection responsibility

Version 0.2.0 uses official Firecrawl services for data execution. It does not implement direct-source bypasses, a proxy fleet or IP rotation.

A managed route does not justify a universal guarantee about proxy technology, unlimited availability or protection from all account and access risks. This wrapper makes no such promise. Provider errors and source limits must remain visible to the operator.

Earlier claims of zero IP risk and safe direct access at scale are withdrawn. The [historical audit](../../docs/NATIVE-LIVE-AUDIT-20261001.md) included a direct Wayback HTTP 429 and only modest repeat observations. Historical GREEN_SAFE and YELLOW_SHIELDED labels describe old metadata, not current guarantees.

See [release scope](../../docs/RELEASE-SCOPE.md).
